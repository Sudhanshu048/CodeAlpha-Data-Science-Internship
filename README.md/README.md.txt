#  CodeAlpha Machine Learning Internship

This repository contains all the tasks completed ,focusing on real-world machine learning problems using Python.

The work demonstrates data preprocessing, model building, evaluation, and result interpretation using industry-standard tools.



----- Internship Tasks Overview -----

  Task 1: Iris Flower Classification
- Built a classification model to predict the species of Iris flowers
- Dataset features: Sepal & Petal measurements
- Applied Logistic Regression
- Achieved high classification accuracy
- Evaluated using accuracy score and confusion matrix

📂 Folder: `Task-1-Iris-Flower-Classification`



  Task 3: Car Price Prediction
- Predicted used car prices using regression techniques
- Performed data cleaning, encoding, and feature selection
- Built a regression model to estimate prices accurately
- Evaluated model performance using error metrics

📂 Folder: `Task-3-Car-Price-Prediction`



  Task 4: Sales Prediction
- Predicted sales based on advertising expenditure
- Analyzed impact of TV, Radio, and Newspaper ads
- Built a Linear Regression model
- Visualized relationships between variables

📂 Folder: `Task-4-Sales-Prediction`
